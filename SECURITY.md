# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

## Reporting a Vulnerability
CivixRecord-OS handles civic audiovisual records and municipal meeting telemetry. If you discover a vulnerability or potential leakage in in-camera session filtering:
- Please report it via GitHub Private Vulnerability Reporting or email oss@civixrecord.org.
- Do not create public GitHub issues for undisclosed security flaws.
- We aim to respond and provide triage within 48 hours.
